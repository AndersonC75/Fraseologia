# Frazeologia Pro

Aplicativo em Python/Tkinter para organizar frases em categorias e subcategorias.

## Funcionalidades

*   Criação de categorias principais (abas).
*   Criação de subcategorias aninhadas.
*   Adição, edição e remoção de frases.
*   Cópia de frases com duplo clique ou botão direito.
*   Organização manual da ordem das abas.
*   Temas claro e escuro.
*   Persistência de dados em `frases.json`.

## Uso

1.  Execute o `frazeologia.exe` (se compilado) ou `python frazeologia.py`.
2.  Use os menus para gerenciar categorias, organizar abas e mudar o tema.
3.  Use os botões laterais para adicionar/editar/remover subcategorias e frases na aba ativa.
4.  Dê duplo clique ou use o botão direito em um item para copiar seu texto.
